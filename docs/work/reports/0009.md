# Goal 0009 implementation report

## Attempt A1

Implemented the authorized TTS playback polish and layered voice configuration goal from `docs/work/active/0009-tts-playback-polish-and-layered-voice-configuration.md`.

### Configuration and voice ownership

- Added the portable `[tts].windows_voice_preference = "Zira"` app setting and checked-in default.
- Windows voice resolution now prefers an explicit valid book voice ID, then deterministic preferred-name matching (including en-US tie-breaking), then the OS default with a warning.
- Added versioned `BookReaderOverrides`; omitted fields inherit the current app config on every open.
- Reader settings patches record book-scoped intent, while global model/resource/thread/logging fields remain app-owned.
- Legacy whole-`AppConfig` book caches migrate appearance/reader behavior fields but never manufacture backend/voice overrides.
- Filesystem and remote persistence now write/read explicit book overrides rather than treating a frozen full app config as book intent.

### Playback and recovery

- TTS batch progression now carries a runtime-local continuation cursor across 8-item refill batches and bounded normalization-window rebuilds, preventing completed items from replaying while preserving legitimate multi-chunk identity.
- The simulated regression now drives 300 ordinary first-sample boundaries and asserts exact ordered, single-start canonical identities across multiple windows.
- Backend/voice changes are validated before session mutation. Invalid Piper model/config/eSpeak resources produce an actionable failure and leave the last-known-good session intact.
- Added transactional failed-Piper regression coverage.

### Text-only identity

- Text-only row styling and follow now use the same high-frequency canonical playback ID; stale page-local snapshot indices are no longer used to decide the visible row.

## Attempt A2 correction

Implemented the director-authorized correction from `docs/work/reviews/0009-a1-real-desktop-rejection.md` while preserving the A1 branch/report lineage.

### Production corrections

- Added a production-owned `TextOnlyRowProjection` used by the text-only renderer. The pretty-to-text-only action re-arms follow for the current canonical playback identity, and playback page transitions refresh the document projection only when the lightweight cursor actually changes pages.
- Added stale-book playback filtering so cancellation/boundary events from a closed or different source cannot update the active reader state.
- Bounded the left panel to a resizable 240–460 px range and wrapped long TTS/voice diagnostics inside the available width.
- Replaced destructive in-content close controls with a persistent top-chrome `Close book` action and confirmation-before-destruction semantics.
- Close-book ordering is now stop/cancel TTS, persist bookmark and overrides, then clear the session and return to Starter. Persistence failure leaves the reader open with a visible status.
- Safe Quit now stops TTS, waits for the persistence terminal event, and only then sends the native egui `ViewportCommand::Close`; persistence failure cancels the close. The old concurrent flush/shell-close plan was removed.
