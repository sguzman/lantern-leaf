# Goal 0019 — Native PDF visual stability — A6

## Result

A6 corrected the rejected A5 production topology while preserving the accepted A1-A5 renderer, page-domain, visual-first, scheduling, stale-result, zoom, and residency behavior. The native application now creates one shared `PdfNativeService` per app instance. Its dedicated native thread owns the single `NativePdfRenderer`/Pdfium binding and serializes metadata validation, native page-count lookup, and page rasterization. Source-open effects use a bounded typed metadata request through that handle; the egui thread does not construct or bind Pdfium.

Detached effect execution now catches unexpected panics and emits terminal `SourceOpenProgress(phase = failed)` plus `CommandFailed(code = effect_panicked)` events, preventing a stranded in-progress operation.

## A6 implementation

- Replaced the source-open metadata probe with the shared native service.
- Passed the same service handle from `PdfRenderWorker` into `EffectContext` in both native app constructors.
- Added a deterministic production-topology lifecycle test: one service, valid two-page metadata, malformed/header-only rejection, then page-1 rasterization; metadata and raster results carry the same native worker thread identity.
- Added a worker wait timeout so metadata wakeups cannot be lost between the channel check and the scheduler wait.
- Added a lightweight off-UI PDF container precheck so header-only input fails normally before entering Pdfium parsing.
- Added the detached effect panic terminalization test.
- Extended the hosted Windows renderer probe to run the shared metadata+raster lifecycle test before the native startup probe.

## Validation evidence

- Focused shared native lifecycle test: passed in both `src/lib.rs` and native `src/main.rs` test harnesses in a dedicated process (`--ignored`); it proves valid two-page metadata, header-only rejection, same-owner rasterization, and same worker-thread identity.
- Detached effect panic terminalization test: passed in both egui test harnesses.
