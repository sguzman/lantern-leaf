# Goal 0020 — Continuous native PDF viewport and practical zoom

## Attempt lineage

Attempt A1 was rejected by director review. A2 continues the same branch/report lineage on `codex/0020-continuous-pdf-viewport-and-zoom-a2`, synchronized with director `main` commit `c9097d3` and preserving A1 commit `3a7c34c`.

## A2 corrections

- The actual continuous viewport visible set is published by the egui surface and consumed by the canonical planner. The planner alone submits bounded raster work; the reader no longer submits ad-hoc render requests.
- Native page dimensions/aspect ratios are collected off-thread by the existing Pdfium owner through asynchronous metadata and cached by source/revision. Texture completion cannot discover layout geometry.
- Geometry is cached behind a source/metadata/viewport/zoom key; visibility and current-page lookup use indexed binary search rather than scanning every page on ordinary repaint.
- Fit width and Fit page use the current viewport and target page dimensions, display the effective percentage with the fit mode, and remain distinct from Reset/100% manual mode.
- The PDF surface is now horizontally and vertically scrollable, so 200–400% manual zoom remains navigable.
- Zoom, fit, resize, and metadata geometry transitions capture and restore a page/intra-page/viewport witness; explicit page jumps take precedence.
- Visible pages are included in the canonical keep/pin set and residency capacity expands as needed to avoid evicting actually visible pages.

## Delivered

- Replaced the single-page PDF presentation with a continuous vertical egui page stack.
- Added deterministic page-slot geometry with bounded visible/overscan selection, stable center-anchor current-page derivation, mixed aspect-ratio support, and intra-page jump anchors.
- Kept native raster work on the existing PdfRenderWorker/Pdfium ownership path; placeholders and geometry are handled on the egui thread.
- Preserved source/generation/page/render-size identity and source-switch invalidation. Visible pages remain pinned by existing residency rules.
- Added explicit continuous-stack jump targeting for Previous/Next controls.
- Expanded zoom stepping to 25–400% and added Fit width, Fit page, Reset/100% state. Logical page geometry updates immediately while native rasters catch up asynchronously.
- Preserved existing EPUB, TTS, pretty-rendering, scheduler, and native service behavior.
