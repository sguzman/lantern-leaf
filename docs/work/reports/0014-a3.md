### Diagnosis and implementation

A2 captured a semantic anchor at each geometry-key transition, immediately restored from estimated heights, and then replaced those estimates with measurements on later frames. During rapid edits this allowed each intermediate frame to become the next capture source, producing the observed distant excursion and occasional wrong final location.

A3 adds a stateful multi-frame pretty reflow transaction. The last stable rendered frame records a lightweight viewport witness, preferring a visible canonical highlighted sentence/segment and retaining its viewport-local position. The first geometry change captures that witness once; subsequent geometry-key changes clear stale measured heights but retain the original anchor and only update the transaction key. Estimates select a bounded anchor neighborhood; the final restoration offset is computed after the anchor region is measured. Pending canonical TTS follow remains authoritative, and wheel/drag input cancels stale automatic correction. Once the pending correction is applied on a stable frame, automatic ownership ends and ordinary virtualization resumes.
