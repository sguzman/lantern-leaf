## Implementation

The previous `pretty_page` lifecycle cleared measured block heights on a geometry-key transition while leaving egui's persisted raw scroll offset attached to the old geometry. The new policy captures that offset before invalidation as a semantic block index plus within-block offset, invalidates stale measurements, and restores the corresponding offset against the new estimates. It applies to horizontal-margin/content-width, text-metric, block/heading-spacing, media-sizing, and compound geometry changes through the existing geometry key. A legitimate pending canonical TTS follow skips idle restoration so the existing canonical follow/consume behavior remains authoritative. Rendering remains bounded and image/pretty work remains off the egui thread.

The existing image sizing path and its binding-limit/aspect-ratio verification were preserved; non-binding limits remain allowed to produce no visible size change.
