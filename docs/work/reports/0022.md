# Goal 0022 — native PDF embedded text / TTS

## Result

Implemented the native trustworthy embedded-text path on the existing Goal 0019/0020 Pdfium owner.

- Extended the process-wide `PdfNativeService` with asynchronous page-aligned Pdfium text extraction.
- Results carry source identity, generation/revision, native page count, page payloads, worker-thread evidence, and terminal success/failure through the receiver result.
- Added a named deterministic trust gate for coverage, minimum density, replacement/control garbage, and duplicate-page noise.
- Visual PDF open remains independent; enrichment runs on the native worker and stale source generations are discarded.
- Added atomic `ReaderSession` adoption that preserves native PDF page identity and feeds existing sentence/search/text-only/TTS state without arbitrary repagination.
- Accepted text is persisted through the existing versioned `PdfRenderPrecomputedState` cache shape.
- No Python, Docling, OCR, Quack-check, or external recovery process was added to the production path.
