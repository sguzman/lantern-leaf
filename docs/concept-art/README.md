# Concept Art

This directory preserves visual design explorations that are important to LanternLeaf's product direction but are **not implementation contracts**.

Concept art is deliberately kept beside the durable project documentation so strong visual ideas do not disappear into chat history. A concept may inform later GUI goals, but the current implementation remains governed by `docs/project/`, `docs/architecture/`, accepted work goals, and verified QA evidence.

## Preserved concepts

- [`epub-tts-reader/`](epub-tts-reader/) — dark jade EPUB reader with first-class TTS, synchronized sentence highlighting, a persistent playback surface, and a dense visual-reading inspector.

When a concept becomes implementation work, extract its intended behaviors into an explicit goal/architecture document rather than treating pixels as a hidden specification.
